# 故事正文

每個資料夾對應「What are you hungry for?」的一個選項，裡面每個檔案是一道菜的正文。

- `forgiveness/`、`desire/`、`recognition/`、`love/`、`nothing/`
- 檔名固定：`01-aperitif.txt`、`02-entree.txt`、`03-plat-principal.txt`、`04-fromage.txt`、`05-dessert.txt`、`06-digestif.txt`

格式：純文字，段落之間空一行。同一段裡的換行會被接起來，不用刻意去掉。
段首縮排由網頁自動加上，正文不需要空格縮排。

目前五個資料夾都暫時放著摺頁的文字。
